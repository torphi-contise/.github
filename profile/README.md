# Torphi Contise

Software development since 2003.

Maintains two products:

**[BAYBO](https://baybo.app)** is a personal net worth tracker published on the
App Store and Google Play. It answers three questions: how much a person put in,
how much they have today, and whether that did better or worse than CDI, Bitcoin
or the dollar. Every value is locked at the exchange rate of the day it was
recorded, so the number shown on a given date remains that date's number.

**[Bullgate](https://bullgate.dev)** is an open-source, mobile-first platform for
identity, access and billing. Bullgate Access owns registration, login, sessions,
recovery and the cases where the simple path breaks down, such as a phone number
that already belongs to another account. Bullgate Billing owns catalogue, plans,
subscriptions, one-time purchases, offers and entitlement delivery, keeping
payment itself with external providers. Running it yourself is free.

Repositories: [Concepts and documentation](https://github.com/torphi-contise/bullgate-concepts) · [Bullgate Access](https://github.com/torphi-contise/bullgate-access)
